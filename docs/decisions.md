# 決定事項

計画時点（`~/.claude/plans/clever-scribbling-graham.md`）からUIプロトタイプ検証を経て変わった/具体化した決定事項をここに記録する。

## データモデルの難易度命名

計画時点では文字数ベースの難易度を `short`/`medium`/`long` としていたが、UI検討の結果「レベル」として `beginner`/`intermediate`/`advanced`（初級/中級/上級）と呼ぶ形に統一した。判定基準（文字数の閾値）は計画時点のものを踏襲する。

| レベル | 内部値 | 文字数 |
|---|---|---|
| 初級 | `beginner` | 〜45 |
| 中級 | `intermediate` | 46〜80 |
| 上級 | `advanced` | 81〜 |

CSV取り込み（Stage 1）実装時は、`versant_practice/difficulty.py` の判定結果をこの命名で `Problem.difficulty` に格納する。

## 画面構成（4画面）

`prototype/` で検証した構成をそのまま本実装の土台とする。

1. **設定選択画面**: レベル（4択・単一選択、ミックス=全レベル）とアクセント（4択・単一選択、米/英/豪/ミックス）を選んで開始
2. **リスニング画面**: 進捗バー（クリア数/レベル内問題数）、ストリークバッジ、音声は画面遷移時に自動再生、再生ボタンでリプレイ、速度切替（0.75x/1x/1.25x/1.5x）
3. **回答画面**: テキスト表示、リプレイボタン、解説欄（枠のみ、内容は未定でよい）、セッション内正答率、○できた/✕できなかったの自己評価
4. **セッションリザルト画面**: レベル内の全問題をクリアした時点で表示。正答率・ベストストリーク・問題数、「もう一度」または「設定を変える」

## 間違えた問題の同セッション内再出題

✕（できなかった）を押した問題は、2〜4問先のキューに再度差し込まれる。レベル内の全問題が一度は正解するまでセッションは終わらない設計（`cleared`セットで管理）。永続的な間隔反復（日をまたぐ復習）ではなく、あくまで1セッション内の即時再出題。

## UI演出

正誤時に効果音（Web Audio APIで生成、音声ファイル不要）・バイブレーション・絵文字リアクションのオーバーレイを表示。画面遷移にはフェード+スライドアニメーションを付ける。

## 未決定・要検証（プロトタイプ止まりの項目）

- **iOS実機での自動再生**: ○/✕タップ直後に次の音声を自動再生する実装にしているが、iOS Safariの自動再生ポリシーによりブロックされる可能性がある。実機で要確認（対策として、音声再生はボタンのクリックイベントと同一コールスタック内で同期的に呼び出す形にしてあるが、確定的な回避策ではない）
- **ブラウザ音声合成のアクセント再現度**: プロトタイプは端末内蔵の音声合成でアクセントを仮再現しており、英/豪ボイスが入っていない端末では無言で代替の発音になる。本番の事前生成TTS音声では解消される想定
- **ホスティング先**: 未確定（GitHub Pages案あり、要ユーザー確認）
- **縦横レイアウト**: 縦向き前提の設計。横向き・低高さ画面向けに簡易な詰め表示（`@media (max-height: 500px)`）は入れたが、本格的な横向き最適化はしていない
